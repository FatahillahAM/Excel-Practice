1Gambaran besar

Satu aplikasi web di Vercel. Data, login, dan file disimpan di Supabase. Excel di laptop berbicara langsung ke aplikasi saat kamu menekan Finish.

2Dari Start sampai skor

Satu latihan dari awal sampai akhir. Warna label menunjukkan siapa yang bekerja: web, Excel, atau server.

Server

Data acak + kunci jawaban dihitung program, lalu disimpan sebagai "snapshot" percobaan. AD-3

Server

File .xlsm diisi

Template yang sama (dengan tombol Finish) diisi data, ditandai token unik dan alamat server. AD-4

Excel

Kamu mengerjakan

Butuh bantuan? Pilih soal dan buka hint di web: −5 poin, dicatat di server. AD-5

Excel

Klik Finish

Macro menyimpan dan mengirim file. Kalau diblokir, upload lewat web, hasilnya sama persis. AD-6

Server

Identitas dicek

Token dan "sidik jari" macro harus cocok. Kalau tidak, file ditolak dengan alasan yang jelas.

Server

"File terkirim"

Server langsung membalas, lalu menilai di belakang layar supaya Excel tidak menunggu. AD-11

Web

Results muncul sendiri

Layar exam mengecek status tiap 2 detik dan pindah ke Results begitu nilai selesai.

Alasan file ditolak (sama di macro, upload, dan web)
  • NOT_EXCELBukan file Excel.
  • IDENTITY_ALTEREDToken hilang atau macro berubah, misalnya karena di-Save As ke .xlsx.
  • NOT_THIS_ATTEMPTFile dari percobaan lain.
  • ALREADY_GRADEDPercobaan ini sudah dinilai.
  • ATTEMPT_CLOSEDPercobaan sudah dibatalkan atau ditutup.

3Isi aplikasi: empat bagian

Aturan penting ada di satu tempat (inti). Bagian lain hanya boleh memakai inti, tidak boleh membuat aturannya sendiri.

Kenapa begini? Spec meminta "menambah level tidak mengubah mesin" dan "file yang sama selalu dapat skor yang sama". Dengan inti tunggal, jalur macro dan upload pasti memakai aturan yang sama, dan Level 5–9 nanti cukup dipasang sebagai modul baru.

4Status satu percobaan

Hanya satu bagian kode yang boleh mengubah status ini AD-5. Database memastikan hanya ada satu percobaan aktif di semua perangkat.

5Progres dihitung, bukan disimpan

Streak, rekor, level yang terbuka, dan pips selalu dihitung ulang dari riwayat percobaan yang sudah dinilai, ditambah daftar freeze AD-7.

Riwayat (satu-satunya sumber)
  • Practice 4 · Level 3 — graded 85 Sabtu
  • Practice 3 · Level 3 — graded 92 Jumat
  • Rabu — freeze
  • Practice 5 · Level 3 — abandoned tidak dihitung
Yang terlihat di Dashboard
  • Streak 12: hari dengan ≥1 percobaan dinilai, dihitung per tanggal di zona waktumu yang tetap AD-8
  • Rekor: waktu tercepat per item, lulus atau gagal
  • Level terbuka dan pips 4/5 dihitung dari percobaan yang sudah dinilai

Kenapa? Hasil bisa datang dari macro, upload, penilaian ulang, Practice again, atau perangkat lain. Kalau angka disimpan dan di-update di banyak tempat, cepat atau lambat angkanya tidak cocok lagi. Dihitung dari riwayat, angkanya selalu benar.

6Production dan Preview

Versi yang kamu pakai sehari-hari terpisah dari versi uji. Setiap file Excel tahu ke server mana ia harus mengirim AD-13.

Dipakai latihan
Production
  • Vercel, cabang main
  • Supabase project prod
  • File dari sini mengirim ke sini
Untuk mencoba fitur
Preview & lokal
  • Vercel, cabang lain
  • Supabase project dev
  • Perubahan database lewat file migrasi, dicoba di dev dulu

Catatan biaya: semuanya memakai paket gratis. Project Supabase gratis akan pause kalau tidak dipakai 7 hari. Kalau itu terjadi, buka dashboard Supabase dan klik restore.

7Tiga hal yang diuji paling awal

Sebelum soal-soal dibuat, tiga hal ini dibuktikan dulu dengan Excel 2021 di laptopmu.

S1

File hasil isian tetap utuh

Template yang diisi data masih membuka tombol Finish dan macro-nya di Excel 2021.

Kalau gagal: ganti mesin file ke Python, tanpa mengubah bagian lain.
S2

Rumus terbaca benar

Server membaca rumus dan nilai dari file yang disimpan Excel, termasuk rumus yang di-copy ke bawah.

Kalau gagal: sama seperti S1.
S3

Finish bisa mengirim

Macro mengirim file lewat HTTPS dari laptop dan menampilkan pesan terkirim atau gagal.

Kalau gagal: Upload tetap jalan sampai diperbaiki.

8Istilah singkat

Token percobaan
Kode acak di dalam file .xlsm yang menandai "file ini milik percobaan nomor sekian".
Snapshot
Salinan soal, poin, dan kunci jawaban yang disimpan saat Start, supaya nilai tidak berubah walau konten diperbarui.
Inti
Bagian kode yang berisi aturan (nilai, streak, status). Tidak tahu apa-apa soal tampilan atau database.
Adapter
Penghubung inti ke dunia luar: Supabase, file Excel, login Google.
Modul level
Satu folder per level berisi skenario, pembuat data, kunci, hint, dan Tips.
RLS
Kunci di database: setiap baris hanya bisa dibaca pemiliknya.
Spike
Percobaan kecil untuk membuktikan bagian yang berisiko sebelum membangun semuanya.
