Level Node · fokus keyboard

Ring 2px warna ring sebagai lingkaran SVG (r + 5 setelah skala 1,14). Callout menutup saat node lain difokus.

Temuan saat merender (perlu keputusan sebelum spine final):
  • Angka streak desktop tidak muat di rail. Rail pada layar 1280 hanya ±300px; token display-streak 232px + hero-padding 44px berasal dari arah B (hero selebar halaman). Mock ini memakai 150px + padding 24px (3 digit tetap muat). Usulan: display-streak jadi fluid, mis. clamp(120px, 12vw, 232px), dan padding Streak Hero di rail 24px.
  • Week Strip butuh state "hari mendatang" (hari setelah hari ini dalam minggu berjalan). Mock kanonik menghindarinya dengan "hari ini = Minggu"; contoh restarted memakai lingkaran kosong tanpa border sebagai usulan.
  • Baris judul halaman: tombol aksi dari arah C (Setup Guide + Start) dihapus supaya Start hanya ada di Level Callout (aturan satu Primary Button per wilayah).
  • Skor riwayat, waktu rekor, dan angka aktivitas hanya contoh.
